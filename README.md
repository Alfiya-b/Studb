A simple web-based Student Course Management System developed using PHP and MySQL.

## About the Project

This project was created to manage student records and their courses. It allows users to add, update, delete, search, and view student information stored in a MySQL database.

The project was developed as part of learning PHP, MySQL, database operations, and CRUD functionality.

## Technologies Used

* PHP

* HTML
* CSS
* phpMyAdmin
* XAMPP

## How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Create a database named `college`.
4. Create/import the required tables.
5. Copy the project folder into the `htdocs` directory.
6. Open:

`http://localhost/index.php`
